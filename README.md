# 웨딩촬영 시안 사이트 사용 방법

## 폴더 구성

| 이름 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 (첫 화면 · 시안 보기 · 시안 만들기) |
| `시안사진/` | **시안 사진을 넣는 곳** — 여기에 넣으면 사이트에 자동으로 올라가요 |
| `build.js` | 사진 목록을 자동으로 만들어요 (건드리지 않아도 돼요) |
| `netlify.toml` | Netlify 배포 설정 (건드리지 않아도 돼요) |

---

## 1. 처음 한 번만: 사이트 올리기 (GitHub + Netlify)

사진을 넣기만 하면 자동으로 반영되려면, 사이트를 GitHub에 올리고 Netlify와 연결해야 해요.

1. **GitHub** (github.com) 가입 → 오른쪽 위 `+` → `New repository`
   - 이름 입력 (예: `wedding-sian`), Private 선택해도 괜찮아요 → `Create repository`
2. 만들어진 화면에서 `uploading an existing file` 클릭
   → 압축을 푼 폴더 **안의 파일과 폴더 전부**를 끌어다 놓기 → 아래 `Commit changes`
3. **Netlify** (app.netlify.com) → `Add new site` → `Import an existing project` → `GitHub`
   → 방금 만든 저장소 선택
   - Build command: `node build.js` / Publish directory: `dist` (자동으로 채워져요)
   → `Deploy` 클릭
4. 1~2분 뒤 사이트 주소가 생겨요. `Site configuration` → `Change site name`에서 주소를 바꿀 수 있어요.

---

## 2. 시안 사진 올리기 (자동 반영)

1. GitHub 저장소에서 원하는 폴더로 들어가요
   예) `시안사진` → `1_촬영 시안` → `2_야외`
2. 오른쪽 위 `Add file` → `Upload files` → 사진을 끌어다 놓기 → `Commit changes`
3. **1분 정도 뒤 사이트에 자동으로 나타나요.** (Netlify가 알아서 다시 배포해요)

- 사진 이름은 아무거나 괜찮아요. 같은 사진을 두 번 올려도 한 장으로 처리돼요.
- 한 번에 100장까지 올릴 수 있어요. 더 많으면 나눠서 올려 주세요.
- 사진 내리기: 사진 파일 클릭 → 오른쪽 `⋯` → `Delete file` → `Commit changes`
- 폴더 안의 `_여기에_사진을_넣어주세요.txt`는 지우지 마세요. (폴더가 사라지지 않게 해줘요, 화면엔 안 보여요)

## 3. 탭 · 카테고리 바꾸기

**폴더 이름이 곧 화면에 보이는 이름**이에요. 앞의 숫자는 순서를 정할 뿐 화면엔 안 보여요.

```
시안사진/
  1_촬영 시안/      ← 위쪽 탭
    1_실내/          ← 필터 버튼 (전체 / 실내 / 야외 …)
    2_야외/
    3_신부단독샷/
    4_신랑단독샷/
  2_헤어변형/
    1_반묶음/ 2_번/ 3_생머리/ 4_웨이브/ 5_포니테일/ 6_포인트/ 7_신랑헤어/
  3_메이크업/       ← 사진을 넣으면 탭이 나타나요
```

- **새 카테고리 만들기**: `Add file` → `Create new file` → 파일 이름 칸에
  `시안사진/2_헤어변형/8_업스타일/_안내.txt` 처럼 입력 → 아무 글자나 쓰고 `Commit changes`
- **새 탭 만들기**: `시안사진/4_부케/_안내.txt` 처럼 만들면 돼요.
- 사진이 하나도 없는 탭은 화면에 나타나지 않아요. 사진을 넣으면 자동으로 생겨요.

## 4. 사이트 이름 · 문구 바꾸기

`index.html`을 열어 `사이트 설정` 부분만 바꾸면 돼요. (GitHub에서 파일 클릭 → 연필 아이콘)

```js
brand: '웨딩촬영 시안',            // 왼쪽 위 로고 · 첫 화면 제목
coverMark: 'wedding concept book', // 표지 오른쪽 위 작은 글씨
credit: '사진 출처: …',            // 맨 아래 문구
pdfName: '웨딩촬영시안',           // PDF 파일 이름
```

## 알아두면 좋은 점

- 고객이 만든 시안과 ♥ 선택한 사진은 **고객의 기기(브라우저)에 자동 저장**돼요. 같은 기기 · 같은 브라우저로 다시 들어오면 이어서 작성할 수 있고, 다른 기기에서는 보이지 않아요.
- PDF는 A4 가로 크기로 저장돼요. 인쇄 버튼을 쓰면 A4 가로 한 장에 한 페이지씩 인쇄돼요.
- 편집은 PC가 가장 편해요. 휴대폰에서는 화면을 두 손가락으로 확대해서 입력하면 돼요.
- 내 컴퓨터에서 미리 보기: Node.js가 있다면 `node build.js` 실행 후 `dist/index.html`을 열면 돼요.
